📊 Dataset & Sampling Details

14 Input Dimensions
  • Sample Distribution: 120 total samples across 4 balanced tiers (30 samples / 25% each), eliminating class imbalance bias.
  • Feature Set: RAM, Battery, Internal Memory, Primary Camera, Selfie Camera, Clock Speed, CPU Cores, Screen Resolution (H × W), 4G LTE, WiFi, Bluetooth, Dual SIM, Touchscreen.
  • Min-Max Normalization: Raw inputs are normalized to [0, 1] via x_norm = (x - min) / (max - min) so high-magnitude values (RAM 4096) do not dominate smaller features (Clock Speed 2.5 GHz).
  • KNN Configuration: k = 5 (odd integer prevents voting deadlocks; optimal bias-variance balance), using Euclidean distance:
    d(p, q) = √∑(pi − qi)2
